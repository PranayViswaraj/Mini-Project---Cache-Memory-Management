# Lightweight Adaptive Reconfigurable Cache Controller (32-bit) — Phase 1 + Phase 2

Verilog RTL, verification environment, reference model, experiments, open-source synthesis flow and documentation for
a 4 KB (configurable 1–16 KB) 2-/4-way write-through data cache with Random / LRU / Pseudo-LRU replacement,
hardware performance counters (**Phase 1**) and a lightweight, deterministic, no-ML runtime policy selector (**Phase 2**).

**Start with `docs/00_PROJECT_EXPLAINER.md`** (what everything does), then `docs/01_architecture_spec.md`.

## Reproduce (Ubuntu)
```bash
sudo apt-get install -y iverilog verilator yosys python3-matplotlib
# synthesis library (not bundled):
mkdir -p synth/lib && curl -L -o synth/lib/nangate45.lib \
  https://raw.githubusercontent.com/The-OpenROAD-Project/OpenROAD-flow-scripts/master/flow/platforms/nangate45/lib/NangateOpenCellLibrary_typical.lib
python3 sim/run_regression.py --all          # ~10 min, writes results/regression_summary.md
python3 sim/run_experiments.py               # ~10 min, writes results/baseline_results.csv, ablation_results.csv
python3 synth/run_synth.py all               # ~15 min, writes results/synth/
python3 sim/make_report.py                   # tables + figures
```

Tool versions used: Icarus Verilog 12.0, Verilator 5.020, Yosys 0.33, Python 3.12.

## Interface cheat-sheet
`cfg_policy`: `00` Random · `01` LRU · `10` Pseudo-LRU · `11` Adaptive (Phase 2; falls back to LRU in the Phase-1 build).
Key parameters of `cache_top`: `CACHE_BYTES, LINE_BYTES=32, WAYS∈{2,4}, ADAPTIVE_EN, WIN_ACCESSES, SAMPLE_N, MARGIN, CONF_THRESH, MIN_HOLD`.

## Headline findings (see docs 03/04 for the full picture and caveats)
* Policy choice matters on 53 of 100 geometry/workload cases (>5 % spread); no single fixed policy wins everywhere.
* Adaptive vs LRU: up to −24.7 % (2-way) / −38.7 % (4-way) stall cycles, but up to +8.9 % worse where LRU already wins; **not** generally equal to the best fixed policy.
* Diagnosed limitation: leader-group starvation in 4-way conflict-heavy traffic (model-only fix explored).
* Cost (4 KB): +0.39 % / +0.43 % total area (≈ +23 % / +17 % of non-array logic); estimated critical path +86 % / +72 %.

## Integrity notes
All results are generated by the scripts in this repo from the RTL; nothing is hand-entered. Synthetic workloads, fixed-latency memory and
flop-based arrays are limitations, not hidden assumptions — see `docs/05_limitations_and_future_work.md`. Verify every literature reference yourself before citing.
